Focused by design

少一点 Git 焦虑，多一点专注。

从工作区到提交历史，每一个界面只服务于当前任务。复杂能力仍在，但不会抢走你的注意力。

⌘

干净的工作区

已跟踪和未跟踪文件清晰分组。完整源文件差异、行号与改动跳转，让每次提交都有据可依。

⌥

安心地处理冲突

三栏比对当前版本、合并结果和传入版本。按冲突逐处处理，同时保留手动编辑的自由。

⌁

读懂提交历史

拓扑提交图、分支引用、提交人和文件变更集中呈现。搜索、筛选与历史操作触手可及。

A calmer workflow

从改动到远程，顺着完成工作。

Twig 不替你做决定。它在关键步骤给出足够的信息和确认，让 Git 的状态始终可预测。

01
查看改动

按文件浏览，定位每一处增删；只勾选准备提交的内容。

02
写下提交说明

调用历史说明，完成 Commit，或在确认后一次提交并推送。

03
保持分支同步

获取、仅快进拉取、推送。需要处理分叉时，Twig 会如实告诉你。
